# AGENTS

## Project Rules
- Developer documentation for this project lives in `src/main/java/frc/robot/docs`.
- All methods created should include Javadocs so IntelliSense in VS Code shows relevant information.
- When asked to commit, add an appropriate commit message for the staged changes, if the user didn't supply one.
- When appropriate, ask if commits should be split into related, granular commits.

## Persistent Global Formatting Rules
Use this formatting style for all Java files going forward.

- Indentation uses 4 spaces per level (no tabs).
- Method Javadocs use the same indentation level as their method signature.
- Add one blank line between the end of a method (`}`) and the start of the next Javadoc block.
- Keep braces on the same line as declarations/control statements.
- Use a single space after keywords and around operators (`if (...)`, `a + b`, ternary spacing).
- Do not leave trailing whitespace.
